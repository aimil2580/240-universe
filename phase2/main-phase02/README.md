- Author all of your code in the `main.c` file (C/C++) **or** in the `Main.java` file (Java)
- If you use Java, open the `Makefile` and switch the language: comment out `LANGUAGE = c` and uncomment `LANGUAGE = java`
- Compile your code with the make command
```
make
```
- Clean the binary with the clean command
```
make clean
```
- Run the executable by providing a path to a testfile (same command for both languages)
```
./main testfile.txt
```
